# Wild Maps

# Professional Mapping, Route Planning & Roadbook Platform for WordPress

**Build. Explore. Share.**

Wild Maps is a professional WordPress platform for creating interactive maps, travel routes, GPX projects, Points of Interest and printable roadbooks for expeditions, overland journeys, tourism and outdoor adventures.

Designed for travel creators, tour operators, DMCs, bloggers, outdoor professionals and explorers.

---

# Main Features

## 🗺 Route Editor

- Interactive route editor
- GPX import/export
- KML import/export
- CSV import/export
- Native .WMAP project format
- Universal GPX compatibility
- Garmin BaseCamp support
- Google My Maps support
- QMapShack support
- Tracks4Africa GPX support

---
