# Internationalization

Wild Maps uses the standard WordPress translation system.

## Text domain

```text
wild-maps
```

The plugin loads translations from:

```text
languages/
```

## Files

```text
languages/wild-maps.pot
languages/wild-maps-it_IT.po
languages/wild-maps-it_IT.mo
```

## Update template

From the plugin root:

```bash
wp i18n make-pot . languages/wild-maps.pot --domain=wild-maps
```

## Compile Italian translation

```bash
wp i18n make-mo languages/wild-maps-it_IT.po languages/
```

or with gettext:

```bash
msgfmt languages/wild-maps-it_IT.po -o languages/wild-maps-it_IT.mo
```

## Rules

- New PHP strings must use WordPress i18n functions.
- Use `esc_html__()` for escaped visible labels.
- Use `esc_attr__()` for attributes.
- Use `__()` only when escaping happens later.
- JavaScript strings should be prepared for script translations in a later pass.
