# GPX Import UX

This beta bugfix restores a clearer GPX import workflow in Project Studio.

## Scope

- Adds an explicit target project selector to the GPX import panel.
- Supports importing one GPX file.
- Supports importing multiple GPX files.
- Keeps the existing multi-route import behavior.

## Not included

The following items remain in follow-up PRs for issue #59:

- map fit after GPX import
- richer stop/waypoint extraction
- manual editing of imported track stops without changing imported geometry
